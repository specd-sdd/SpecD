  - Domain layer (`packages/core/src/domain/**`) remains free of filesystem/node I/O and outward dependencies (`SpecOverlapError`, `lifecycle-verdict.ts`, `change.ts`).
  - Application layer (`packages/core/src/application/**`) orchestrates domain services (`resolveEffectiveBindings`, `validateSkipChecks`, `executeMatchingPredicates`) through ports without depending on CLI or MCP delivery layers.
  - Composition layer (`packages/core/src/composition/**`) wires `CheckRegistry`, `archiveBindings`, and `transitionBindings` via `resolveWorkflowCheckRegistry` and exposes dual-overload factories (`createArchiveChange`, `createGetStatus`).
- **`default:_global/conventions`**:
  - Naming, ESM `.js` relative imports, `readonly` data contracts, and JSDoc annotations on public symbols are consistently followed across all modified files.
- **`default:_global/error-handling-conventions`**:
  - All thrown errors extend `SpecdError` with stable uppercase snake_case codes (`SPEC_OVERLAP`, `UNKNOWN_CHECK`, `CHECK_NOT_SKIPPABLE`, `CHECK_PREDICATE_FAILED`, etc.).
  - `SpecOverlapError` message is delivery-agnostic (`Cannot archive: specs [...] are also targeted by other active changes.`) and carries `skippable: boolean` so CLI/MCP presenters can format remediation hints appropriate to their surface.
- **`default:_global/testing`**:
  - Co-located mirror test files under `packages/core/test/**/*.spec.ts` use Vitest and cover all normative scenarios added or modified by `archive-schema-checks-and-skip-flag`.
