## Approach / solution outline

Three helpers in `@specd/core`. No `path.join` wrapper.

- `normalizeVcsRoot(raw)` — `path.resolve` plus uppercase drive letter. Call from `rootDir()` / `detect()` of Git, Mercurial, and Subversion. The result is also a valid `cwd` for later CLI invocations.
- `isPathInside(root, candidate)` — resolve both sides, then `path.relative`. Empty means the candidate is the root. A result that starts with `..` or is absolute is outside. Replaces `startsWith(root + path.sep)`.
- `toPortablePath(value)` — replace `\` with `/` only. Do not use `path.posix.normalize` (that collapses `.` and `..`). Existing `normalizeRelativePath` in `packages/core/src/infrastructure/fs/path-confinement.ts` is a different operation.

Call `toPortablePath` at persistence boundaries (graph node constructors, VCS `modifiedFiles`, config-relative display paths). Leave PHP namespace `replaceAll('\\', '/')` local: that backslash is a namespace separator, not a Windows path. PHP PSR-4 `qualifiedName.replace(/\\/g, path.sep)` then `path.join` in `php-language-adapter.ts` (~line 2163) is correct and must not be "fixed".

Atomic writes:

- Shared retry helper on `EPERM`, `EBUSY`, and `EACCES` for `writeFileAtomic`, storage-generation rename, and spec publication directory swap.
- `moveDir` copy-fallback also on `EPERM` and `EXDEV`. Today it only treats `ENOTEMPTY` and `EEXIST` (`packages/core/src/infrastructure/fs/move-dir.ts`).
- "Destination bytes already match" is success only for idempotent `{configPath}/tmp/.gitignore`. Never for artifacts whose new content differs.

Hooks:

- POSIX dialect stays single quotes.
- `cmd.exe` dialect: wrap in `"`, internal `"` as `""`, `%` as `"^%"`, `!` as `"^!"`, double trailing backslashes before the closing quote.
- `windowsVerbatimArguments: true` when spawning `cmd.exe`.
- `windowsHide: true` on Windows `spawn` / `execFile` for hooks and for `git/exec.ts`, `hg/exec.ts`, `svn/exec.ts` (today they pass only `{ cwd }`).
- Hook command text on Windows remains `cmd.exe` syntax. Escaping does not turn bash into cmd. Users who need bash invoke `bash` explicitly.
- When the expanded command is one executable plus arguments, prefer `execFile` and skip the shell.
- `cmd.exe /c` quote-stripping and the 8191-character limit are residual risks. Line draining in `hook-runner.ts` already strips a trailing `\r`.

Hashes and newlines:

- Normalize `\r\n` and `\r` to `\n` before text digests. Do not do this for binary payloads.
- Compare tmp `.gitignore` after the same normalization (`TMP_GITIGNORE_CONTENT` is `*\n!.gitignore\n`).
- Add `.gitattributes` with `eol=lf` for `*.md`, `*.yaml`, `*.yml`, `*.json`.

Graph:

- Indexer already converts relative paths with `.replaceAll('\\', '/')` before persistence (`discover-files`, `index-code-graph`, health, freshness, fingerprints, file/document/symbol/spec node constructors). Do not treat "graph stores backslashes" as an open hole.
- Guard first-colon splits so `^[A-Za-z]:[/\\]` is a drive letter, not a workspace. Sites include language adapters (`typescript` ~1814, `python` ~1142, `php` `splitWorkspacePath` ~288, `go` ~151), `index-code-graph.ts` (many `indexOf(':')`), `sqlite-graph-database.ts` ~1473, `matches-exclude`, `compute-hotspots`, `search-code-graph`, `resolve-symbol-reference`, CLI `resolve-impact-file-selectors.ts` `toGraphDisplayPath`.
- `SQLiteGraphStore.recreate()` already throws if `this.client.isOpen`, then `rm`s `graph/`. Retry deletion of `code-graph.sqlite`, `-wal`, and `-shm` (`journal_mode = WAL` in `sqlite-graph-database.ts` `configureDatabase`). `force: true` does not ignore `EBUSY`.
- Lock file is `graph/index.lock` (`getGraphIndexLockPathForStoragePath`). `recreate()` must not drop an active lease. Lease is existence via `open` `wx`, fd closed immediately (`index-lock.ts`). Release on `exit` is the reliable path. Also listen for `SIGBREAK` on Windows. `SIGTERM` is not delivered like Unix.
- `process.kill(pid, 0)` in `change-repository.ts` `_isPidAlive` works as an existence check; `EPERM` means alive. Windows PID reuse can make a stale lock look owned. Mention, do not redesign locking unless design decides to.

Names:

- Reject Windows device names as a whole path segment on every OS: `con`, `prn`, `aux`, `nul`, `com1`–`com9`, `lpt1`–`lpt9`. Patterns today: change `^[a-z0-9]+(?:-[a-z0-9]+)*$` (`change.ts`), capability `^[a-z0-9_][a-z0-9_-]*$`, workspace `^[a-z][a-z0-9-]*$`. `con-foo` stays legal. Uppercase `Auth` vs `auth` is already rejected by those patterns. Do not add a case-folding spec-id rule.

Tests and repo tooling:

- Replace hardcoded `/tmp`, `/var/www`, and `file:///tmp/...` with `os.tmpdir()`, `path.resolve`, and `pathToFileURL`.
- `chmodSync(..., 0o000)` in `packages/code-graph/test/application/use-cases/get-graph-health.spec.ts` does not make a file unreadable on Windows. Skip or replace on `win32`.
- `lint-staged` in root `package.json` runs `bash -c 'pnpm typecheck'`. Husky uses `.husky/_/husky.sh`. `#!/usr/bin/env node` on the CLI is fine (npm/pnpm `.cmd` shim).
- No `windows-latest` job under `.github/workflows/` (only Gemini workflows). Add one or the regressions return.
- Lockfile already has Windows optional builds for `@ast-grep/napi`, `esbuild`, `rollup`, and `turbo`. `better-sqlite3` is in `pnpm-workspace.yaml` `onlyBuiltDependencies` and needs a prebuild or MSVC. Long paths (`MAX_PATH` / `\\?\`) are a residual risk for the native addon, not a confirmed bug.

- Drive-letter case policy: uppercase the letter only, or also `realpath`? `realpath` fixes symlinks (`/tmp` → `/private/tmp` was cited for macOS prune) but fails when the path does not exist yet. Prefer `path.resolve` + drive case for the VCS root; keep `realpath` only where the code already uses it (`_pruneEmptyParents`).

- Index lock PID reuse. Noted, not selected as a redesign.
- Long-path / `better-sqlite3` native build. Install note, not a code change unless design finds a failing path.
