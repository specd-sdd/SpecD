# Exploration Context — agent-plugin-prompt-injection

Generated: 2026-07-27

## Problem Statement

When agent plugins (`plugin-agent-claude`, `plugin-agent-opencode`, `plugin-agent-copilot`, `plugin-agent-codex`, `plugin-agent-standard`) are installed, there is currently no official mechanism to automatically inject an entry prompt / instructions to the target agent so that it immediately starts using specd (`/specd`, `/specd-new`, `specd graph`, etc.).

## Approach & Architecture Decisions

1. **Centralized Template & Utility in `@specd/skills`**:
   - Add a shared Handlebars template (`agent-instruction.md.tpl`) in `@specd/skills/templates/prompt/`.
   - Expose block manipulation helpers (`injectSpecdBlock`, `removeSpecdBlock`) and rendering logic in `@specd/skills`.
   - Support `extraInstructions` via Handlebars so each agent plugin can append native/runtime-specific instructions to the base specd prompt.

2. **Idempotent Markdown Block Management (`<!-- <specd> -->`)**:
   - Delimit instructions using `<!-- <specd> -->` and `<!-- </specd> -->`.
   - On `install`: Create or update the block in target instruction files (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.github/copilot-instructions.md`).
   - On `uninstall`: Remove the block cleanly without touching surrounding user rules/content.
   - On `update`: Replace only the content inside the block.

3. **Native Hooks & Scripts Support**:
   - For agents supporting native hooks/scripts:
     - **Claude Code**: Deploy native hooks under `.claude/hooks/` + update `CLAUDE.md`.
     - **OpenCode**: Deploy native TypeScript plugin under `.opencode/plugins/specd.ts` + update `AGENTS.md`.
     - **Copilot / Codex / Standard**: Use block injection in `.github/copilot-instructions.md`, `AGENTS.md`, `GEMINI.md`.

4. **Prompt Content Guidelines**:
   - **Main Entry Points**: `/specd` (general orientation with `specd project status --context --graph`) and `/specd-new` (creating a new change).
   - **Code Graph Mandatory**: Code graph (`specd graph`) is mandatory and strongly preferred over raw text tools (`grep`, `glob`).
   - **Index Freshness Check**: Instruct agent to check `stale: true` and execute `specd graph index --format toon` if index is out of date.
   - **Concrete Use Cases**: Include exact CLI commands with `--format toon` for Symbol Search, Blast Radius Impact, Debugging Dependencies, Hotspots, and Spec Coverage.
   - **Workflow Rules & Stop Rules**: Enforce spec-driven changes and strict adherence to skill stop points.
   - **Explicit User Override (Escape Hatch)**: Preserved for narrow, local, direct user overrides.
