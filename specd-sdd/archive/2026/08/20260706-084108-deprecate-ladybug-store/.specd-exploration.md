# Exploration: SQLite specification cleanup

## Current request

Ladybug is no longer part of the SpecD monorepo. The user requested that the
`code-graph:sqlite-graph-store` specification and verification artifacts contain
no references to Ladybug or its former shorthand.

## Evidence

- `code-graph:sqlite-graph-store` is an owned workspace spec.
- `SQLiteGraphStore` remains the supported implementation and no production code
  change is required for this documentation-only correction.
- The existing change already retires Ladybug into an external preservation
  repository and declares SQLite the sole built-in store.

## Decision

Update only the SQLite spec and verify deltas to state its independent contract
without comparing it to, or naming, the retired backend. Preserve the existing
SQLite behavior, scenarios, and recovery boundary.
