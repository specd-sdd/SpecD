# Exploration: go-selectors-python-reexports

## Problem

Two language limitations left open by `code-graph-cross-workspace-imports`:

1. **Go package-qualified selectors.** `models.User{}` after `import "github.com/acme/auth/models"` produces only a file-level dependency on the package files. The selector is never resolved to the `User` symbol, so `USES_TYPE`/`CONSTRUCTS`/`CALLS` across Go packages do not exist, inside or across workspaces. The Go adapter emits no selector facts that the shared resolver could use, and `importMap` stays empty for package imports.
2. **Python names re-exported through `__init__.py`.** `from acme_auth import User` stays unresolved when `acme_auth/__init__.py` only contains `from .models import User`. Python's public surface is module-level declarations; imports remain local aliases and `__all__` is unsupported, so such re-imports are not public routes.

## Context from the previous change

- The shared package helpers (`packageEntryFiles`, `resolvePackageExport`) and the `PackageResolutionFacet` already exist. Go's `entrySurface` returns the non-test files of the package directory with the package surface as `surface`, so `resolvePackageExport` could resolve exported names against the Go package surface once the adapter asks for them.
- Go public bindings exist (uppercase identifiers produce public bindings on the package surface).
- Python's `entrySurface` returns the module or `__init__` file; its `surface` is the path without extension or `__init__`.
- Resolving a Go selector needs: a namespace binding from the import's package name (or alias) to the package, selector facts (`alias.Name`) in the file analysis, and a resolution step. Decide whether the facts belong in `analyzeFile` (parser-authoritative) or are derived from existing call/binding facts.
- Python re-exports need a route model for `from .x import Y` in `__init__` (and optionally static `__all__`). The current spec says aliases stay local unless static metadata proves a public route; decide the exact rule so that it stays conservative.
